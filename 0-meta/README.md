# 0. Meta

Configuration for this personal KB.

1. [kb-config.yaml](kb-config.yaml) — KB identity: your name, language, owner.
   FACE Studio fills this in when it creates your KB; check it only if you
   created this copy yourself, in which case it still has `TODO` values.
2. [life-config.yaml](life-config.yaml) — which folders are sealed, whether
   inner work is on, and the default class of each shareable folder.
3. [cadences.yaml](cadences.yaml) — the daily check-in, the weekly review and
   the quarterly review: what your agent asks and where the answers go.
4. [conventions.md](conventions.md) — your own rules for this KB, which your
   agents follow after FACE's.
5. [log.md](log.md) — one line per change, appended by your agent.
6. [face-lint.yaml](face-lint.yaml) — settings for the structure check.

The exposure rules live at the repo root in [access.yaml](../access.yaml) — see the [root README](../README.md) for how the folders are grouped by who can see them.
