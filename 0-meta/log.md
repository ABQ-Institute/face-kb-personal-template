# Log

Append-only: one line per operation, newest at the bottom. Your agent appends here; nobody edits a line once it is written.

Line format: `- YYYY-MM-DD · <operation> · <what happened, in one line>`

Operations, a fixed list: `ingest` · `query` · `update` · `correction` · `lint` · `review` · `decision` · `schema` · `import`
